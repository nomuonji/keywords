## 1. お宝KWの定義（v10 で置き換え）

3条件が**同時に**成立するものだけを候補にする。

1. **AIが答えられない形式を要求する** — AIの要約で用が足りる語は、上位に出ても来訪しない
2. **AIが量産で強みを出す構造** — 網羅・構造化・出典重視。体験談が本体の題材はAIが負ける
3. **アフィリエイト導線がある** — 誰に払うか、読者が次に何をするかが具体的

**検索ボリュームは合否条件にしない。** 0 は低競合を探した結果として現れることがあるだけで、狙いではない。

### 1.1 クリック動機（AIが満たせない6種）

| 動機 | 中身 | 形式 |
|---|---|---|
| calculation | 自分の条件で金額・回数を出す | 計算機 |
| currency | 今の価格・在庫・空き・締切 | 現況データ |
| coverage | 多数の選択肢を同条件で並べる | 比較表 |
| template | 様式・記入例・定型文が要る | ダウンロード |
| branching | 条件分岐で該当手続きを特定する | 判定フロー |
| local | 近くの店・業者を比べる | 地域比較 |

どれにも当たらない語は「informational」であり、動機が無い＝棄却。

## 3. ゲート（この順で落とす）

1. **実在・同名別義** — 公式一次資料で名称を同定。同名の別対象が需要を食っていないか
2. **クリック動機（I11）** — 6種のどれか。無ければ棄却
3. **形式の不在（I12）** — 1ページ目にその動機を満たす形式が無いか。タイトル＋スニペットで判定し、最終候補は本文を読む
4. **AI制作適性** — 網羅・構造化・出典で勝てる題材か。体験が本体なら不可
5. **アフィリ導線** — 誰に・いくら・どの行動。承認状況は別途
6. **需要** — 補助証拠。測れなければ Lane C（義務・供給・記録・行動）
7. **競合** — `competitionLevel` を記録。high は I8/I12 の条件でのみ残す
8. **YMYL（I9）** — 該当すれば、体制が無い限り棄却

## 4. 既知の天井

- **AI Overviewの中身は直接観測できない。** AIが答えを出しているかは語形と1ページ目から推定している（測定ではない）
- AI経由のクリック率は測れない
- 現況データ（価格・在庫・締切）は更新ループが要る。手法はそこを提供しない
- ドメインの強さは測っていない。`competitionLevel` は1ページ目が核を被覆しているかだけを見る
- Google SERP が取れないときは代替エンジン観測で、順位の同一性は保証されない

## 5. サイクル運用（手法を良くする手順）

1. エージェントが**3候補＋自分の予測**（依頼主が何と言いそうか）を出す
2. 依頼主が各候補に 採用／保留／棄却 ＋ 一言理由
3. 予測が外れたら、原因を**手法の欠陥**か**判断の欠陥**に切り分ける
4. 同じ理由が**2回**出たら不変条件に昇格し、Pack を v+1 に上げる
