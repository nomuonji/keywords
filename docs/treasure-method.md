# Treasure keyword discovery — canonical method

**METHOD VERSION: tsk-v12** (2026-11-10)
**CANONICAL: my-portal intelligence_pack `treasure-keyword-intelligence` v6**

## この文書の役割

叙述の正本は My Portal の Intelligence Pack（v6）。Pack は不変バージョンで、resolver が正確な版を固定できる。
この文書は CI で検査する契約（不変条件ID・コードのフィールド名・`methodVersion` 義務・Pack版ポインタ）で、Pack を更新したら両方のバージョン行を同じ run で更新する。

---

## 1. お宝KWの定義（3条件の同時成立）

1. **AIが答えられない形式を要求する**（動機：calculation / currency / coverage / template / branching / local）
2. **AIが量産で強みを出す構造**（網羅・構造化・出典。体験が本体の題材は不可）
3. **アフィリエイト導線がある**（誰に・いくら・読者の次の行動）

**検索ボリュームは合否条件にしない。** 0 は低競合を探した副作用。

## 2. 不変条件

| ID | 不変条件 | 破った実例 |
|---|---|---|
| **I1** | 受け皿から出発しない（3条件の判定には使う） | 知育玩具カタログに閉じた |
| **I2** | 金額を優先して形式・動機の判定を落とさない | 「金は確実」で競合市場を推奨 |
| **I6** | 需要の欠損は 0 でも「需要なし」でもない（Hold） | 未測定を合格にした |
| **I7** | 発見元・レーン・手法バージョン・cycleIdを記録 | — |
| **I8** | `competitionLevel=high` を記事形式で棄却（I15を優先） | 営業記事10件の語を推奨 |
| **I9** | YMYLは一次資料と体制が無い限り作らない（道具も同じ） | 永代供養の計算機を提案 |
| **I10** | 3条件の同時成立のみ採用 | 競合の不在だけで候補にした |
| **I11** | クリック動機が無い語は棄却 | — |
| **I12** | `editorialCompetitionLevel=high` は棄却。medium は意思決定クエリ限定 | — |
| **I13** | 非自明性：一次資料にのみ存在しモデルの事前分布から列挙できない名前 | 補助金判定・諸費用・引越し実費を提案 |
| **I14** | パターン固定の禁止（1 run に未知パターン1件以上） | 品種名パターンに馴染みかけた |
| **I15** | **編集の競合は `editorialCompetitionLevel` で判定する。** official・EC・SNS・動画・アプリストアは編集の競合に数えない。`competitionLevel` は「その語がすでに使われているか」の参考情報にすぎない | EC10件・記事0件の商品名を「競合high」として棄却した |

## 3. ゲート順

1. 実在・同名別義
2. 非自明性（I13）
3. クリック動機（I11）
4. **編集の競合（I15 / I12）** — ECが並ぶのは商品名クエリでは正常。記事が0〜1件なら空白
5. 形式の不在（計算機・比較表・早見表の有無）
6. AI制作適性
7. アフィリ導線
8. 需要（補助証拠。null は Hold。クラファン支援額は購買意欲の証拠だが検索需要ではない）
9. YMYL（I9）

## 4. 実際に通った例

| 語 | 需要/月 | competitionLevel | editorialCompetition | 判定 |
|---|---:|---|---|---|
| キングバリア（台木用トマト） | 170 | high | **1/10 = low** | 全ゲート通過 |
| グランバギー（台木用ピーマン） | 70 | — | 未測定 | 候補 |
| 永代供養 費用 | 9,900 | high | 10/10 = high | 棄却 |

キングバリアは 上位10件が楽天・Yahoo・種苗店・タキイ公式のみで**編集記事0件**。旧指標では high と出て棄却していた。

## 5. 既知の天井

- 編集判定はタイトルとスニペットのみ。「記事風の商品ページ」は誤判定する
- AI Overview の中身は観測できず、AI十分性は推定
- AI経由のクリック率は測れない
- Ads の測定下限は月10〜20
- ドメインの強さは未計測

## 6. サイクル運用

エージェントが3候補＋自分の予測 → 依頼主が 採用/保留/棄却＋一言 → 予測が外れたら「手法の欠陥」か「判断の欠陥」に切り分け → **同じ理由が2回で不変条件に昇格**し Pack を v+1。
