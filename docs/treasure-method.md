## 1. 合格条件（6つ同時成立）

候補は次の**すべて**を満たすときだけ合格とする。

| # | 条件 | 判定方法 | 実測例 |
|---|---|---|---|
| **C1** | **本人が書ける・書きたい**（一次体験がある、関心がある、または書く意思がある） | 候補を絞った後に依頼主へ確認する。**既存のアカウントや領域に限定しない**（新しい領域でも、書きたいなら合格） | `占い 当たらない` は書きたいから合格。`溶接 歪み 取り` は需要170/月でも書く気がないので不可 |
| **C2** | 需要 ≥10/月 | Google Ads 実測。null は Hold（0 ではない） | `占い 当たらない` = 1,300/月 |
| **C3** | 弱い枠 ≥6/10 | **実Google（Reserp）の1ページ目**で、知恵袋・note・個人ブログ・掲示板・2年以上前のQ&A・タイトル不一致・意図ズレを数える。判定の細則は I11 | `占い 当たらない` = 6（知恵袋3＋ameblo＋note＋YouTube） |
| **C4** | 収益導線がある | CPC ≥¥100、または1成約 ≥1,000円、または広告主の存在（外部の支払い証拠） | `占い 当たらない` = CPC ¥448・広告主あり |
| **C5** | 同名別義に食われていない | 公式一次資料で名称を同定し、別対象の需要と混ざっていないか確認 | ティンブロの3,600/月は大宮のレストランだった |
| **C6** | **一次資料の取得経路がある**（本人の体験／引用可能な当事者投稿＋投稿日／取材先） | C1の「書ける」を実行可能にする条件。経路が無い語は、どれだけ数字が良くても記事にならない | `転職 後悔` は数字が通るが、本人の転職体験か引用可能な当事者投稿が無ければ書けない |

**C1 が最後に加わった条件**であり、39サイクルの失敗を解いた。C1 を外すと「需要×低競合×収益」を満たす B2B 技術語（溶接歪み取り、材料記号、タップ下穴）が出てくるが、依頼主は書かないので価値がゼロだった。

## 2. 不変条件（違反した run の結論は無効）

| ID | 不変条件 | 破った実例 |
|---|---|---|
| **I1** | **実Google以外で競合を確定しない。** Brave・ddg・exa・bing は参考。順位・顔ぶれは互いに一致しない | 溶接歪み取りをBraveで3点と判定→Googleでは6点。材料記号で専門メディア10本と判定→Googleでは圏外 |
| **I2** | **不在を主張しない。** 測るのは「存在の不足」「形式の差分」「既存サイトの目次との差分」だけ | 「SERPに無い＝空白」を3回誤用した |
| **I3** | Ads の null は Hold。0 でも「需要なし」でもない | サジェスト0件を不在と断定した |
| **I4** | **C1 は事前フィルタではなく確認工程。** 既存アカウント・既存領域を探索範囲の上限にしない。書けないと確認できた語だけを棄却する | C1を「既存領域のみ」と解釈すると、新しい領域の候補を測る前に捨ててしまう |
| **I5** | 弱い枠＝勝てる枠ではない。**上位ページの内容を読んで判断する** | タップ下穴径で、個人サイトが業者10社より充実していたのを見落とした |
| **I6** | 発見元・手法バージョン・cycleId・棄却ゲートを記録する | — |
| **I7** | 一次資料から名前を採る（非自明性）。モデルの事前分布から出た語は棄却 | 補助金判定・中古車諸費用・引越し実費 |
| **I8** | 具体化すると競合が強まる（B2B）。「狭くすれば空く」は成立しない | ステンレス溶接歪み取りは業者10社、本体は弱い枠3 |
| **I9** | 専門DB・愛好家サイトが全領域を埋めている前提で始める（GI図鑑、列島宝物館、伝統野菜図鑑、やさい暦、hayamihyou） | 「編集メディアが書いていない」を空白の証拠にした |
| **I10** | YMYL は一次資料と体制が無い限り作らない | 永代供養の計算機を提案 |
| **I11** | **枠の数え方の細則**。①Reserp が返すログインページ（`google.*`）や地図エントリは**結果ではないので除外**し、除外数を記録する（弱い枠に数えない）②Quora・知恵袋は**投稿が2年以上前なら弱い枠**、新しいものは数えない③YouTube は**専門チャンネルの解説なら数えない**、個人の体験談なら数える | `転職 失敗 その後` でノイズ1件を弱い枠に数えていた。除外すると6点で合格。`転職 後悔 理由` のYouTube3本は個人の体験談動画 |
| **I12** | **感情語は空き、取引語は埋まる。** 同じ領域でも、後悔・不安・疲れ・当たらないといった感情の語は弱い枠が立ち、売却・比較・ミスマッチ・依存といった業務／取引の語は専門職が押さえている。記事は感情語で書き、送客先だけ取引語へ向ける。取引語で正面から競わない | 転職＝後悔7点↔ミスマッチ5点、実家＝感情語は空き↔空き家売却0点、占い＝当たらない6点↔依存5点 |
| **I13** | **競合の濃さは単価ではなく「誰が書けるか」で決まる。** 資格・立場・実務がないと書けない領域（医療・葬祭・不動産・採用）は、単価が低くても専門職が押さえている | ペットロスは月12,100でCPC ¥37（最安）だが弱い枠3。動物病院・霊園・葬祭が占める |

## 3. 手順

1. **候補を先に集める。** 既存アカウントの範囲で足切りしない（C1 を事前フィルタに使わない）。集めた候補のうち、需要・競合・収益が立ったものを依頼主に見せ、書けるか・書きたいかを確認する
2. 領域を問わず候補を作る（サジェスト・一次資料・既存記事のコメント・依頼主の体験）
3. Ads で需要と CPC を測る（`keyword_screen_batch`）
4. **Reserp で実Googleの1ページ目を取る**（`scripts/serp-reserp.py`）
5. 弱い枠を数える（C3）。6点未満なら棄却
6. 上位ページの**本文を読む**（I5）。内容が薄いことを確認してから着手を決める
7. 同名別義を確認（C5）
8. 記録して保存、readback

|---|---:|---:|---:|---|

## 5. 既知の天井

- Reserp は課金。1リクエスト単位で費用がかかる
- Google Ads の測定下限は月10前後。それ以下は Hold
- 弱い枠スコアは内容を読まないと反転する
- 「本人が書けるか」は依頼主にしか判定できない

## 7. 台帳（機械可読・CI検査）

| 台帳 | ファイル | 役割 |
|---|---|---|
| 方法論バージョン | `docs/method/versions.json` | 各版の変更・理由・追加した条件/不変条件。doc の changelog と1対1 |
| 合格条件 | `docs/method/criteria.json` | C1〜C6 の閾値・判定方法・反例・導入版 |
| 勝ちパターン | `docs/method/patterns.json` | verified / candidate / rejected の3状態。verified は evidence 必須 |

### 規則の固定

`scripts/treasure-score.ts` が I11 の採点規則を実装し、`scripts/treasure-score-smoke.ts` が公開済みの採点結果（転職 後悔=7、ペットロス=3、空き家 売却=0）を固定する。**規則を変えたらテストが落ちるので、方法論を黙って書き換えられない。**
